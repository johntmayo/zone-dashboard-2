Design exploration · not the live dashboard

Tools & Resources prototypes

Two clickable approaches to the same information. Both keep Tools and Resources in the sidebar, open internal workspaces without rearranging a directory, and include Event Planning Templates plus a Disaster Case Management referral.

Prototype A · Featured Bench

Spatial hierarchy. Batch Tagging is a large primary object. Disaster Case Management is a highlighted band. Secondary items are compact rows with a clear Open vs New tab hint.

Prototype B · Field Handbook

Sequential and typographic hierarchy. Batch Tagging is a full-width “Start here” command. Everything else is a numbered index, more like a printed field guide than a dashboard of tiles.

How to review

  1. Open Tools, then Batch Tagging. Select a few addresses, go Back to Tools, and reopen — selections should still be there.
  2. Open Event Planning Templates and try PDF / Make a copy (prototype toasts only).
  3. Switch to Resources. Try the referral form, then Reimbursements.
  4. Click Tools or Resources in the sidebar from inside a workspace — you should return to that directory, not stay trapped in the workspace.
